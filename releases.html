NIAHCIA operator download center

Use this page to get the current packaged software for running NIAHCIA. Release assets will appear automatically when each repository publishes a GitHub Release.

Pre-alpha: NIAHCIA does not have production releases yet. Empty components below simply have not published their first tagged build.

What should I install?

Full Node

Install NIAHCIA Node / Core.

CPU Miner

Install NIAHCIA Miner and connect it to a NIAHCIA node or compatible mining endpoint.

AI Compute Worker

Install NIAHCIA Compute and connect it to the network.

Explorer Operator

Install NIAHCIA Explorer. It is not required for consensus.

Web Operator

Install NIAHCIA Web. It is a client, not a network dependency.
